# C++ Codebase Documentation

This section provides documentation for the C++ components of the project. The codebase is organized into several main modules:

-   **`lib/`**: Core library functions, including matrix operations, image processing utilities, configuration management, and geometric calculations. See [`lib.md`](lib.md) for more details.
-   **`feature/`**: Components related to image feature detection, description, and matching (e.g., SIFT, BRIEF). See [`feature.md`](feature.md) for more details.
-   **`stitch/`**: Algorithms and classes for image stitching, including camera models, blending, and warping. See [`stitch.md`](stitch.md) for more details.
-   **`common/`**: Common utilities and definitions used across the project. See [`common.md`](common.md) for more details.

This documentation aims to provide a high-level understanding of each module's purpose and key components. For detailed API information, please refer to the Doxygen-generated documentation.
